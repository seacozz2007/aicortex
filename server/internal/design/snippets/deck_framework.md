## Deck framework

Structure the HTML deck as:

1. Title slide — product name + tagline
2. Problem — pain points
3. Solution — your approach
4. Product — key screens or flows
5. Traction / proof (if applicable)
6. Business model (if applicable)
7. Team (if applicable)
8. Ask / next steps

Each slide: `<section class="slide" data-aicortex-id="slide-N">` with flex-centered content.
Use keyboard-friendly navigation (`ArrowRight` / `ArrowLeft`) via minimal inline JS if needed.
