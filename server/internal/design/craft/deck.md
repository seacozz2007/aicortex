# Deck Craft

- Build a single HTML file with one `<section>` per slide.
- Each slide: full viewport height (`min-height: 100vh` or `100dvh`).
- Use `@media print` and slide navigation hints for presentation flow.
- Typography scales for projection — large headings, high contrast.
- Do not generate PPTX; HTML only in this phase.
- Tag key elements with `data-aicortex-id` for comment mode.
